Principles

Decisions I keep making

Written the way I'd record them for a team: as architecture decision records.

ADR-001

The architect stays through delivery Accepted

Context
Designs handed over at kickoff drift from what gets built within a few sprints.
Decision
Own the architecture through release: in planning, in code review, in the incident channel.
ADR-002

Write the spec before the code, and before the prompt Accepted

Context
AI agents produce code faster than teams can agree on what it should do.
Decision
Spec-driven engineering: a reviewed, testable specification is the input for both people and agents.
ADR-003

Agents get guardrails, not blank cheques Accepted

Context
Enterprise codebases carry compliance, security and long-lived conventions.
Decision
Give agentic tooling explicit boundaries, review gates and patterns, so speed doesn't cost trust.
